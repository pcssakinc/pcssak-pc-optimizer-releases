# PCssak 0.8.0 알려진 제한

최종 갱신: 2026-08-23

이 문서는 공개된 **미서명 무료 얼리액세스** 휴대용 Prerelease
[`v0.8.0`](https://github.com/pcssakinc/pcssak-pc-optimizer-releases/releases/tag/v0.8.0)의
제한을 설명합니다.

## 배포·신뢰 경계

- 공식 앱 압축 파일은 Windows x64용
  `PCSSAK_0.8.0_x64_Portable.zip`입니다.
- SHA-256은
  `88d9e2012b329242ab2903268f46ec5b4a6f69d06582d262cf706704cd0406aa`입니다.
- 설치기를 사용하지 않으며 사용자 소유 폴더에 압축을 풀어야 합니다.
- 이 단계의 `PCSSAK.exe`는 의도적으로 Authenticode 서명을 하지 않습니다.
  Windows에서 알 수 없는 게시자, SmartScreen 또는 백신 경고가 표시될 수 있습니다.
- 코드 서명, 게시자 인증서 확인, SmartScreen 평판과 외부 법률 전문가 검토는
  연기 상태이며 통과한 관문이 아닙니다.
- 해시 일치는 파일이 같은 GitHub Release에 게시된 자산과 같다는 뜻이지,
  소프트웨어가 무해하다는 독립적인 보장은 아닙니다.

## 검증 경계

- 자동 회귀시험 결과는 물리 Windows PC의 실측을 대체하지 않습니다.
- Windows 10/11 Home·Pro, DPI, 다중 모니터, 파일시스템, 관리자 권한, 보안 제품,
  설치·업데이트·제거와 복구의 전체 행렬은 완료되지 않았습니다.
- Windows x86은 지원하지 않으며 첫 패키지는 x64 전용입니다.
- Prerelease 다운로드가 열린 뒤 추가 PC에서 실사용 측정을 수집합니다. 각 결과에는
  정확한 릴리스 해시와 Windows 환경을 함께 기록해야 합니다.
- 성능 또는 탐지 정확도 주장은 실제로 측정한 장치·데이터·작업 범위를 넘어
  일반화하지 않습니다.

## 제품 범위 경계

- 첫 무료 얼리액세스는 읽기 전용 진단 중심으로 제한합니다. 시스템 변경 기능과
  Pro 기능은 제공되지 않을 수 있습니다.
- 업데이트 확인은 사용자가 요청할 때만 실행해 결과를 표시합니다. 새 버전이 있으면
  사용자가 별도 공식 다운로드 페이지 버튼을 누를 수 있습니다. 확인 동작이 페이지를
  자동으로 열거나 패키지를 자동 다운로드·실행·설치·롤백하지 않습니다.
- 휴대용은 로컬 상태가 전혀 없다는 뜻이 아닙니다. 설정, 로그, 격리 정보, 복구 기록
  또는 다른 앱 자료가 추출 폴더 밖에 저장될 수 있습니다.
- 추출 폴더 삭제는 전체 데이터 제거 절차가 아닙니다. 실제 Release에 포함된
  `UNINSTALL_AND_LOCAL_DATA.md`를 따르세요.

## 라이선스·소스 의무

- 외부 법률 검토를 미뤄도 제3자 라이선스 의무는 미뤄지지 않습니다.
- 모든 공개 Prerelease에는 공개 자산 기준이 정한 SBOM, 제3자 고지, Qt 런타임
  매니페스트, 라이브러리 교체 안내, 소스 제공 안내와 정확한 Qt/PySide 대응 소스
  압축 파일이 유지되어야 합니다.
- 필수 라이선스·소스 자료가 없거나 해시가 다르면 게시를 차단합니다.

## 경고·결함 발생 시 안전 대응

출처, 정확한 파일명, SHA-256 또는 추출 내용물을 확인할 수 없으면 실행하지 마세요.
해당 복사본 사용을 중단하고 개인정보를 제거한 증거만 보존한 뒤 보안 문제는
[SECURITY.md](../SECURITY.md), 일반 결함은 [SUPPORT.md](../SUPPORT.md)를 따르세요.
