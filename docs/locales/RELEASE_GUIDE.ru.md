## Статус

Первый общедоступный тест теперь опубликован как неизменяемый GitHub Prerelease
[v0.8.0](https://github.com/pcssakinc/pcssak-pc-optimizer-releases/releases/tag/v0.8.0)
для Windows x64.

- Версия: `0.8.0`
- Пакет: `PCSSAK_0.8.0_x64_Portable.zip`
- Формат: переносимый ZIP без установщика
- Подпись: намеренно отсутствует на этапе бесплатного раннего доступа
- SHA-256: `88d9e2012b329242ab2903268f46ec5b4a6f69d06582d262cf706704cd0406aa`

Windows может показать «Неизвестный издатель», SmartScreen или предупреждение антивируса.
Подпись, проверка издателя, внешняя юридическая проверка, репутация SmartScreen и полная
матрица Windows отложены и не имеют статуса `PASS`.

## Перед запуском

1. Скачивайте файл только с официальной страницы Releases этого репозитория.
2. Проверьте точное имя пакета и сравните SHA-256 с `SHA256SUMS.txt`.
3. Не запускайте отсутствующий, переименованный или не совпадающий по хешу файл.
4. Проверьте архив и папку антивирусом и распакуйте только в папку пользователя.
5. Остановитесь и сообщите о предупреждении или поведении с непроверенным источником.

Когда пользователь нажимает **Проверить обновления**, PCssak показывает состояние.
Если доступна новая версия, пользователь может отдельно нажать кнопку официальной
страницы загрузки. Страница не открывается автоматически, а пакет не скачивается,
не запускается, не устанавливается и не откатывается автоматически.

Сообщайте о воспроизводимых проблемах, не связанных с безопасностью, через
[GitHub Issues](https://github.com/pcssakinc/pcssak-pc-optimizer-releases/issues),
предварительно удалив личные данные. Для уязвимостей используйте
[закрытый канал безопасности](../../SECURITY.md), а не публичный Issue.
