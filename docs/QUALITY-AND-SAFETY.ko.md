# 품질·안전 공개 기준

PCSSAK PC Optimizer는 “오류가 없을 것”이라는 선언 대신 검증 가능한 증거와 정확한 실패 안내를 공개 기준으로 삼습니다.

## 게시 전 필수 조건

1. 소스 기준점과 빌드 산출물의 커밋·버전·채널 연결
2. 모든 공개 자산의 SHA-256 목록
3. 설치 파일 서명 상태와 게시자 확인
4. SBOM 및 제3자 라이선스 고지
5. 실제 Windows 행렬 결과와 알려진 제한
6. 실패·취소·부분 성공을 성공으로 표시하지 않는 UI 계약
7. 범위 밖 파일·레지스트리·드라이버 변경이 없다는 검증
8. 복구 절차와 심각 결함 발생 시 배포 중단 기준

## 결과 표현

- 성공: 요청 범위가 검증 가능하게 완료됨
- 건너뜀: 정책·호환성·권한 조건으로 안전하게 제외됨
- 실패: 완료되지 않았으며 사유와 대안이 표시됨
- 취소: 사용자가 중단했으며 이미 처리된 범위가 구분됨

성능 향상 수치는 같은 장치·같은 작업의 WPR/WPA A/B 측정이 있을 때만 공개합니다.
