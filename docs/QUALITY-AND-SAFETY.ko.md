# 미서명 무료 얼리액세스 품질·안전 기준

PCssak은 얼리액세스 빌드에 오류가 없거나 모든 검증을 마쳤다고 주장하는 대신,
검증 가능한 증거와 정확한 제한을 공개합니다.

## 결과 상태

- **PASS:** 정확한 릴리스 전용 절차가 검증 가능한 증거와 함께 완료됨
- **DEFERRED:** 향후 상용 릴리스 관문으로 의도적으로 옮기고 이를 공개함
- **NOT_RUN:** 적격 실행 또는 증거가 없음
- **FAILED:** 절차가 완료되지 않았거나 서로 충돌하는 결과가 발생함

`DEFERRED`, `NOT_RUN`, `FAILED`를 `PASS`로 표시하지 않습니다.

## 미서명 휴대용 Prerelease 게시 전 필수 조건

1. 승인된 소스 커밋, 버전 `0.8.0`, 채널, Windows x64 빌드와
   `PCSSAK_0.8.0_x64_Portable.zip`의 추적 가능성
2. 비밀 키, 토큰, 원본 사용자 증거 또는 개발 전용 라이선스 자료가 없는 깨끗하고
   검토된 소스 기준점과 빌드 기록
3. 절대 경로, 상위 경로 이동, 심볼릭 링크, 재분석 지점, 예상하지 않은 실행 파일과
   시험 전용 파일을 거부하는 정확한 휴대용 압축 파일 목록
4. `SHA256SUMS.txt` 자신을 제외한 모든 공개 Release 자산의 대소문자를 구분한
   정확한 파일명별 SHA-256
5. 릴리스 매니페스트, SPDX SBOM, 결정적 제3자 라이선스 패키지, Qt 런타임
   매니페스트, 고지, 교체 안내, 소스 제공 안내와 정확한 Qt/PySide 대응 소스
6. 릴리스별 알려진 제한, 업데이트·롤백, 로컬 데이터 제거 안내와 11개 현지어 안내
7. 정확한 압축 파일 후보의 악성코드 검사 결과와 통제된 압축 해제·실행·종료·정리
   스모크 시험 1회 이상. 해결되지 않은 탐지는 게시를 차단함
8. Draft Prerelease 게시 전에 로컬과 Draft의 자산명·개수·크기·SHA-256을 독립 비교

## 명시적으로 연기한 관문

첫 미서명 무료 얼리액세스 Prerelease에서는 다음 항목을 `DEFERRED` 또는
`NOT_RUN`으로 공개할 수 있습니다.

- Authenticode 코드 서명, RFC 3161 타임스탬프와 게시자 인증서 신뢰
- SmartScreen 평판과 서명된 게시자 사용자 경험
- 외부 법률 전문가 승인
- 전체 물리 Windows 10/11 Home·Pro, DPI, 파일시스템, 관리자 권한, 복구, 성능과
  보안 제품 행렬

연기 정책은 허위 서명 주장, 누락된 라이선스·소스, 잘못된 해시, 검토하지 않은 자산
목록 또는 알려진 파괴적 결함을 허용하지 않습니다.

## 게시 중단 조건

다음 중 하나라도 확인되면 게시를 중단합니다.

- 버전, 소스 커밋, 파일명, 크기 또는 해시 불일치
- 예상하지 않았거나 누락·중복·위험한 압축 구성원
- SBOM, 고지, 라이선스, Qt 런타임 기록 또는 대응 소스 누락
- 비밀정보, 비공개 로그, 사용자 자료, 내부 증거 또는 개발 전용 파일 포함
- 해결되지 않은 악성코드 탐지, 실행 실패, 데이터 손실 위험, 권한 경계 결함 또는
  오해를 유발하는 성공 상태
- 연기하거나 시험하지 않은 관문을 통과로 설명하는 문서

## 불변 게시

GitHub Release는 먼저 Draft Prerelease로 만듭니다. 승인된 모든 자산을 첨부하고
검증한 뒤 게시합니다. 게시한 뒤 `v0.8.0` 태그와 자산을 조용히 교체하지 않습니다.
수정은 새 버전과 새 불변 Release로 제공합니다.
